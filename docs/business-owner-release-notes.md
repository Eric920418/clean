# 後台新功能釋出說明

**對象：業主 / 內容管理員**
**版本：2026-05-15 Section CMS 上線**
**前台網址：https://needfix.com.tw**
**後台網址：https://needfix.com.tw/admin**

---

## 一句話總結

**「服務詳情頁」現在可以像積木一樣自由組裝**：每個區塊可以重新排列、隱藏、新增、刪除，同一種類型的區塊還能加多個。

---

## 你可能會用到的 3 個新功能

### 1. 新增服務不必再填網址代碼

**舊版**：你新增「冷氣深度清洗」時要自己填一個 `aircon-cleaning` 的英文代碼，業主常會卡住。

**新版**：只要填中文名稱「冷氣深度清洗」，系統自動產生網址。
例：「冷氣深度清洗」→ `/services/leng-qi-shen-du-qing-xi`

> 同名服務會自動加 `-2 / -3` 後綴避免衝突。

### 2. 服務詳情頁的「區塊管理」

新位置：`/admin/services/[每個服務的編輯頁]/sections` 或從編輯頁點藍色卡片「**頁面區塊管理**」。

每個服務有 8 種預設區塊：

| 區塊 | 功能 |
|---|---|
| Hero 主視覺 | 頁面最上方大圖 + 標題 |
| Intro 故事區 | 圖文並排介紹服務理念 |
| 重點說明 + 特色清單 | 「為什麼這項服務重要？」+ 重點 bullets |
| 前後對比圖 | 清洗前後並排 |
| 施作過程相簿 | 圖片格子展示過程 |
| 常見問題 | 可摺疊的 FAQ |
| CTA 號召區 | 預約 / 來電橫幅 |
| 推薦其他服務 | 自動帶入其他服務卡片 |

加上**新增的萬用文字塊**（共 9 種），業主可以用它放「優惠公告」「最新消息」這類自由格式內容。

#### 在區塊管理頁可以做什麼

- ⬆️⬇️ 上下移：調整顯示順序
- 👁 顯示 / 隱藏：暫時不想顯示某個區塊
- ✏️ 編輯：改標題、圖片、內容
- 🗑 刪除：永久移除（至少要留一個區塊）
- ➕ 新增：可以加同類型多個（例如兩個 Gallery、兩組 FAQ）

### 3. 同類型可以加多個（這是最大改變）

**舊版**：每個服務只能有「一份」FAQ、「一份」相簿。

**新版**：可以加無限多個。例子：
- 「冷氣深度清洗」服務頁加兩組 FAQ：「服務 FAQ」+「保固 FAQ」
- 加兩個相簿：「分離式案例」+「窗型案例」
- 加多個對比圖區，分別放不同案例

每個區塊的內容完全獨立，加圖到 A 區塊不會影響 B 區塊。

## 操作指南

### 想加一個「優惠公告」區塊

1. 進「我們的服務」→ 找到要加的服務 → 點「編輯詳細內容」
2. 點藍色卡片「頁面區塊管理」
3. 右上角「+ 新增區塊」
4. 選「萬用文字塊」
5. 在新出現的區塊上點 ✏️ → 填標題與內文 → 儲存
6. 用 ⬆️⬇️ 移到想顯示的位置

**前台 1 分鐘內反映**（系統有快取，最久要等 60 秒）。

### 想暫時藏起 FAQ 區

1. 同上進到「頁面區塊管理」
2. 找到「常見問題」那一列
3. 點 👁 變成 👁‍🗨（劃掉）
4. 前台 60 秒內 FAQ 區會消失，但內容還在，隨時可以打開

### 想加第二個相簿

1. 進「頁面區塊管理」
2. 「+ 新增區塊」→ 選「施作過程相簿」
3. 新區塊出現後點 ✏️ → 跳到該區塊的圖片管理頁
4. 上傳圖片（可多選）
5. 回到區塊管理頁，把它移到想要的位置

## 注意事項

1. **slug 上線後不能改**：服務一旦建立、網址就固定了。改網址會破壞 SEO 與已分享連結，所以後台**不開放修改**。如果真的要改網址，要刪掉重建（不建議）。

2. **Hero 區塊隱藏要小心**：Hero 是頁面最上方的主視覺，隱藏後首屏會直接跳到下一個區塊，視覺上會比較空。建議只在你打算重新設計時才隱藏。

3. **「推薦其他服務」是自動的**：這個區塊會自動列出其他在架服務，無需手動編輯（按 ✏️ 會提示）。

4. **刪除區塊會清掉裡面的內容**：刪掉一個 Gallery 區塊，該區塊的圖片也會一起從 R2 清掉。**先想清楚再按**。

## 遇到問題？

任何看到「**錯誤訊息**」、**頁面開不了**、**儲存沒反應**，請立刻聯繫技術窗口並附上：
- 你做了什麼動作（哪個頁面、按了什麼按鈕）
- 出現的錯誤文字截圖
- 影響哪個服務（slug 或名稱）

我們有 backup 可以還原到 2026-05-15 任何一刻的狀態。
